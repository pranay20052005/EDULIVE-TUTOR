# EduLive

EduLive is a live online tuition platform for students from 6th to 12th standard, with course access, live classes, recordings, notes, assignments, mock tests, attendance, and performance tracking.

## Development

To run the app locally, install the project dependencies and start the Vite/TanStack development server.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run the ESLint checks

## Tech stack

- TanStack Start
- TypeScript
- React
- Vite
- Tailwind CSS
